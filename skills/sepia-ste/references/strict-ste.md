# Strict STE: explicit opt-in only

Apply the requested scope only. This checklist is not the full standard or dictionary.

1. Confirm the requested edition, document scope, language, and domain glossary from available context. The cached baseline is Issue 9 (January 2025); do not call it the latest without verification. Ask only for missing information essential to compliance.
2. For an English compliance review, obtain an authorized full edition, including writing rules and dictionary, plus the applicable project/company terminology. Prefer an available local copy. If absent, explain the gap and offer the official request link in `../cache/sources.json`; do not silently download or redistribute the standard.
3. Check all applicable rules against that edition, not just this summary. Check approved vocabulary, meanings, parts of speech, permitted technical nouns/verbs, grammar, procedures, descriptions, warnings, and terminology consistency.
4. Do not use contractions. Retain required words, including articles. Use direct procedural instructions, normally one instruction per sentence, with applicable exceptions checked against the standard. Do not force an invented actor into a sentence.
5. Check procedural sentences against the 20-word limit and descriptive sentences against the 25-word limit, using the edition's counting rules and exceptions. A whitespace count is only a screening aid, not proof.
6. Preserve literals and factual content. Report any remaining exceptions rather than quietly rewriting commands or changing meaning. Do not inject Sepia-style variety, synonyms, or informal phrasing that conflicts with STE.
7. Report scope, edition, resources checked, unresolved findings, and review limitations briefly. Without full rules, dictionary, terminology verification, and an actual applicable-rule review, label the result **STE-oriented; full compliance not verified**, never compliant or certified. Even a completed review is not independent certification.

ASD-STE100 is controlled English. For Chinese or other languages, retain the requested language and apply transferable principles only; disclose that this is not ASD-STE100 compliance. Translate into English only when requested. Strict mode ends with the requested task unless the user explicitly makes it persistent.
